# tariq-ahmad.github.io

Personal site of **Tariq Ahmad**, AI & Engineering Lead: <https://tariq-ahmad.github.io>

A hand-written static site with no build step and no framework. It covers selected work, how I approach engineering, my career path, stack and recognition.

## Run locally

Open `index.html` in a browser. There is nothing to install.

## Structure

| File | Purpose |
|---|---|
| `index.html` | Page content, SEO tags, structured data and the inline icon set |
| `style.css` | Styling, including the light and dark themes |
| `script.js` | Theme toggle, mobile menu, scroll-spy and reveal-on-scroll |
| `og-image.jpg` | Share image used by LinkedIn and other link previews |
| `favicon.svg`, `apple-touch-icon.png` | Site icons |

## Notes

- Light and dark themes follow the visitor's OS setting until they pick one with the toggle.
- Motion (page grid, reveal animations, theme fade) is switched off for visitors who prefer reduced motion.
- Icons are from [Font Awesome Free](https://fontawesome.com) (CC BY 4.0). Fonts are JetBrains Mono and Space Grotesk from Google Fonts.
